# v0.2.2 — nativeFull runtime tuning & open-source docs

**Full changelog:** [CHANGELOG.md](../../CHANGELOG.md)

## Highlights

- **Runtime tuning** via dart-define / env: flush interval, batch/queue limits, log sampling (`SKYWALKING_LOG_SAMPLE_RATE`; ERROR logs always kept).
- **`TopologySimulator`** moved to `test/support/` (not part of the public API).
- **`doc/OPEN_SOURCE.md`**: standalone use — only SkyWalking OAP gRPC **11800** required (no app backend).
- OTLP-era helper scripts archived under `scripts/archive/`.

## Breaking changes (since 0.1.x)

If you upgrade from **0.1.x** or early **0.2.0** previews:

| Removed | Use instead |
|---------|-------------|
| OTLP / hybrid agent modes | **`nativeFull` only** (gRPC **11800**) |
| `SKYWALKING_OTLP_ENDPOINT`, `dart-otlp` | `SW_AGENT_COLLECTOR_BACKEND_SERVICES=host:11800` |
| `bin/verify_otlp.dart` | `dart run bin/verify_native.dart` |
| `usesOtlpTraces` / `usesOtlpMetrics` / `usesOtlpLogs` | Removed in **0.2.1** |

OAP must expose native agent gRPC **11800** and (for Meter dashboards) **dart-native-meter** rules — see [doc/oap/OAP_SETUP.md](../oap/OAP_SETUP.md).

## Environment variables (0.2.2+)

| Key | Default | Purpose |
|-----|---------|---------|
| `SW_AGENT_COLLECTOR_BACKEND_SERVICES` | `127.0.0.1:11800` | OAP gRPC address |
| `SKYWALKING_FLUSH_INTERVAL_SEC` | `5` | Periodic flush interval |
| `SKYWALKING_MAX_BATCH_SIZE` | `32` | Flush when queue reaches this size |
| `SKYWALKING_MAX_QUEUE_SIZE` | `512` | Drop oldest when full |
| `SKYWALKING_LOG_SAMPLE_RATE` | `1` | Sample non-ERROR logs `0–1` (ERROR always kept) |

See [README.md](../../README.md) for the full dart-define table.

## Verify

```bash
export SW_AGENT_COLLECTOR_BACKEND_SERVICES=127.0.0.1:11800
export SKYWALKING_SERVICE_NAME=my-app
dart run bin/verify_native.dart --quick
```

